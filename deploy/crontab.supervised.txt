# Cron Meta Ads Auto-Pilot — PHASE SUPERVISÉE (launch_paused=true).
# À coller via `crontab deploy/crontab.supervised.txt` sur le VPS.
#
# Pas de ligne `launch` ici : pendant la validation tu lances à la main une
# seule fois (les ads sont créées EN PAUSE). Ça évite d'empiler chaque jour
# des vidéos Creatify payées qui ne diffuseront jamais.
#
# optimize : toutes les heures. No-op tant qu'aucune ad n'est ACTIVE
# (le bandit n'agit que sur les ads actives), donc zéro risque budget.
0 * * * * cd /root/automatisation && .venv/bin/python src/orchestrator.py --action optimize >> logs/cron.log 2>&1
#
# dashboard : résumé quotidien par email à 20h (si SMTP configuré)
0 20 * * * cd /root/automatisation && .venv/bin/python src/orchestrator.py --action dashboard >> logs/cron.log 2>&1
#
# Une fois la créa validée :
#   1. `--action activate`  (démarre le budget sur la 1re fournée)
#   2. mettre meta.launch_paused=false dans config/config.json
#   3. `crontab deploy/crontab.txt`  (réactive le launch quotidien direct ACTIVE)
